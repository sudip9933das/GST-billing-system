# BillBook - GST Invoice

Open `index.html` in a browser, or host it with GitHub Pages. No database: data stays in that browser.

1. **My shop**: save shop details, GSTIN, logo and signature once.
2. **New bill**: add customer and products, pick a design.
3. **Download PDF**, **Print**, or **Send on WhatsApp**.

WhatsApp links cannot attach files. "Open customer's chat" saves the PDF and opens the chat; attach it there. "Share PDF file" (where the browser supports it) attaches it, and you pick the contact.

Use **My shop > Save backup** regularly.
